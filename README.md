# 🧩 Sistema Académico (Python - POO)

Proyecto universitario desarrollado en **Python** bajo el paradigma de **Programación Orientada a Objetos (POO)**.  
Permite gestionar **estudiantes, docentes, materias, actividades, asistencia, notas y biblioteca**,  
con persistencia de datos en archivos **CSV**.

---

## 📂 Estructura del proyecto

sistema_academico/
│
├── datos/ → manejo de archivos CSV (gestor_csv.py)
├── modelos/ → clases base del sistema (persona, docente, estudiante, materia)
├── modulos/ → funcionalidades adicionales (actividad, asistencia, biblioteca, notas)
├── utils/ → constantes y carpeta para guardar archivos CSV
│ └── csvs/
│
├── main.py → punto de entrada del programa
├── .gitignore → exclusión de archivos innecesarios
└── README.md → documentación del proyecto
